# AI_LOG — история использования AI в FormCraft

## Контекст

Тестовое задание: автономный сервис форм отклика для карьерной платформы студентов. Обязательный сценарий: менеджер создаёт форму → публикует ссылку → студент отвечает → менеджер видит ответы.

## Как использовался AI

AI-ассистент применялся для:

1. **Проектирования MVP.** Выбран Node.js 20+, Express, HTML/CSS/vanilla JavaScript и локальный JSON вместо отдельной БД. Это позволяет запустить проект командами `npm install` и `npm start`.
2. **Создания интерфейса.** Сформированы админ-панель, конструктор вопросов, предварительный просмотр, публичная форма, экран результатов.
3. **Реализации бизнес-сценария.** Добавлены публикация по уникальной ссылке, проверка ответов на клиенте и сервере, локальное сохранение, экспорт CSV и базовая аналитика.
4. **Исправления по итогам ручного тестирования.** Изначально варианты для вопросов типа «один вариант», «несколько вариантов» и «выпадающий список» вводились неудобно. Добавлены отдельные поля и кнопки добавления/удаления вариантов.
5. **Улучшения логики черновиков.** Разрешено сохранять незавершённые формы; полная проверка вопросов выполняется при публикации.
6. **Защиты истории ответов.** После первого ответа запрещено изменять структуру опубликованной формы, но разрешено менять название и описание. Так старые заявки остаются интерпретируемыми.
7. **Подготовки к сдаче.** Созданы README, сценарий проверки, описание ограничений; удалена внешняя загрузка шрифтов.

## Почему выбраны эти решения

- Приоритет — работоспособный основной сценарий, а не количество дополнительных возможностей.
- Не требуется аккаунт, облако, API-ключ или отдельная СУБД.
- Локальное хранение и простая структура кода делают MVP удобным для проверки.
- Редактирование структуры после получения ответов ограничено намеренно: иначе колонки и ответы могут перестать соответствовать друг другу.

## Проверки

- Синтаксическая проверка серверного и клиентского JavaScript через `node --check`.
- Проверка основных обработчиков API с тестовым адаптером Express: создание черновика, сохранение пустого вопроса, отказ в публикации незавершённой формы, публикация завершённой формы, отправка ответа, блокировка изменения структуры и возможность правки описания.
- Полный запуск через `npm install` и браузерная проверка остаются обязательными перед сдачей: в среде подготовки проекта загрузка npm-зависимостей не завершилась.

## Ограничения

- Админка открыта без авторизации по условиям задания.
- Хранение в JSON не предназначено для конкурентных записей под большой нагрузкой.
- Аналитика приближённая и учитывает события браузерных сессий.
- AI помогал создавать и проверять код; окончательная ответственность за тестирование и сдачу проекта остаётся за разработчиком.
