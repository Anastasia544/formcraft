# FormCraft — конструктор форм для карьерной платформы

FormCraft — автономный MVP, позволяющий менеджеру без программиста создать форму отклика на стажировку или мероприятие, опубликовать её по уникальной ссылке и просматривать ответы студентов.

## Требования

- Node.js **20 или новее**
- npm (входит в поставку Node.js)

Никакие API-ключи, облачные сервисы или отдельно устанавливаемые базы данных не нужны.

## Запуск

В корне репозитория выполните **ровно две команды**:

```bash
npm install
npm start
```

После запуска откройте **http://localhost:3000** (перенаправление в `/admin`).

При необходимости порт настраивается переменной окружения `PORT`:

```bash
# macOS / Linux
PORT=4000 npm start

# Windows PowerShell
$env:PORT=4000; npm start
```

## Сценарий проверки

1. Откройте `http://localhost:3000/admin` — вход и регистрация не требуются.
2. Нажмите **«Создать форму»**, введите название, добавьте вопросы. Поддерживаются: короткий текст, развёрнутый ответ, email, один вариант, несколько вариантов, выпадающий список. Для вариантов выбора используйте кнопку **«+ Добавить вариант»**.
3. Нажмите **«Сохранить черновик»**: можно сохранить форму без вопросов или с незаполненными вопросами и вернуться позже.
4. Завершите вопросы и нажмите **«Опубликовать»**. Скопируйте ссылку вида `/f/<id>`.
5. Откройте ссылку в новой вкладке, заполните форму и отправьте ответы.
6. В админке нажмите **«Ответы»**. Просмотрите заявки, статистику просмотров и конверсии; при желании скачайте CSV.
7. Перезапустите сервер и убедитесь, что формы и ответы сохранились.

## Работа с опубликованными формами

- Пока ответов нет, опубликованную форму можно редактировать, сохраняя прежнюю ссылку.
- После появления первого ответа **структура вопросов блокируется**, чтобы не нарушить соответствие старых ответов вопросам. При этом можно менять название и описание.
- Для анкеты с другой структурой создайте новую форму.
- Кнопка сохранения опубликованной формы называется **«Сохранить изменения»**, а не «Сохранить черновик».

## Технологии и хранение

- Сервер: Node.js 20+, Express.
- Интерфейс: HTML, CSS, JavaScript без сборщика.
- Данные: `data/db.json`, создаётся автоматически при первом запуске.
- События аналитики (просмотры, начало заполнения, прогресс, отправка) также хранятся локально.
- Внешние шрифты и CDN не используются; для запуска нужен только npm-пакет Express.

## Маршруты

| Адрес | Назначение |
| --- | --- |
| `/` | Переход в админку |
| `/admin` | Список форм и конструктор (без авторизации) |
| `/f/:id` | Публичная форма студента |
| `/admin/forms/:id` | Ответы и аналитика |
| `/api/forms` | API создания и списка форм |
| `/api/forms/:id` | API чтения и изменения формы |
| `/api/forms/:id/publish` | Публикация |
| `/api/forms/:id/submissions` | Отправка и просмотр ответов |
| `/api/forms/:id/analytics` | Показатели заполнения |

## Ограничения MVP

- Авторизация не реализована в соответствии с условиями тестового задания. Не используйте приложение для настоящих персональных данных в открытом интернете без защиты.
- JSON-файл подходит для локальной демонстрации и небольшой нагрузки, но не для многопользовательской промышленной эксплуатации.
- Статистика по браузерным сессиям приблизительная и не является полноценной продуктовой аналитикой.
- Если вы публикуете репозиторий с реальными тестовыми ответами, **не загружайте их в GitHub**: файл `data/db.json` исключён из git и создаётся автоматически.
